# CLI Reference

Domdb provides three top-level commands: **download**, **query**, and **output**. All commands accept global options `--json` / `-j`, `--help` / `-h`, `--help` / `--hv`, `--version` / `-V`.

## download

Download verdicts from domsdatabasen.dk.

```bash
domdb download
domdb download --directory ./my-cases
```

## query

Search cached verdicts for legal research. All query subcommands share a common set of filters.

### query index

Build metadata index for fast queries. Run after downloading new cases.

```bash
domdb query index
domdb query index --keyword "trafik" --from 2020-01-01
```

### query count

Count verdicts matching the query.

```bash
domdb query count --keyword "trafik"
domdb query count --paragraph "straffeloven § 237" --from 2015-01-01 --to 2024-12-31
```

### query list

List verdicts matching the query. Supports `--format table` (default) or `--format json`.

```bash
domdb query list --keyword "trafik" --from 2024-01-01 --to 2024-12-31
domdb query list --keyword "vold" --court "Østre Landsret" --format json -n 20
```

**Shared query flags** (apply to `index`, `count`, and `list`):

| Flag | Description |
|------|-------------|
| `--keyword, -k` | Require ALL keywords (case insensitive); searches metadata, or body with `--full-text` |
| `--paragraph, -p` | Legal paragraph reference, e.g. `"straffeloven § 237"` or `"§ 117 stk. 1"` |
| `--from` | Verdict date on or after (YYYY-MM-DD) |
| `--to` | Verdict date on or before (YYYY-MM-DD) |
| `--full-text, -f` | Also search verdict body text for keywords (paragraph search always includes body) |
| `--court` | Filter by court name (substring match on court/author) |
| `--subject` | Filter by case subject (substring match) |

**`list` only flags**:

| Flag | Description |
|------|-------------|
| `--number, -n` | Maximum number of results to list (default: 50, -1 for all) |
| `--format` | Output format: `table` or `json` (default: table) |

## output

Commands for exporting data.

### output bib

Convert JSON case files to BibTeX format.

| Flag | Default | Description |
|------|---------|-------------|
| `--number, -n` | `-1` (all) | Maximum number of verdicts to process |
| `--output, -o` | `resources/cases.bib` | Output BibTeX file path |

### output hay

Convert JSON case files to Hayagriva YAML format (for Typst).

| Flag | Default | Description |
|------|---------|-------------|
| `--number, -n` | `-1` (all) | Maximum number of verdicts to process |
| `--output, -o` | `resources/cases.yml` | Output Hayagriva YAML file path |

### output md

Convert JSON case files to Markdown format.

| Flag | Default | Description |
|------|---------|-------------|
| `--number, -n` | `-1` (all) | Maximum number of verdicts to process |
| `--output, -o` | `resources/cases.md` | Output Markdown file path |
| `--split-by-year, -s` | `False` | Split output by year into separate files |
| `--keyword, -k` | — | Filter cases containing ALL given keywords (case insensitive) |
| `--full-text, -f` | `False` | Also search the full verdict body text (HTML/PDF), not just metadata |

### output j2e

Convert JSON case files to EVID directory structure.

| Flag | Default | Description |
|------|---------|-------------|
| `--number, -n` | `-1` (all) | Maximum number of cases to process |
| `--output, -o` | `evid` | Output directory for EVID structure |
